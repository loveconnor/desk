# Original BenQ ScreenBar (AR17)

`original-screenbar.glb` is an original, locally authored approximation of the
original ScreenBar, not a BenQ-provided CAD asset. Geometry is generated by
`node scripts/build-screenbar.mjs` from `src/Application/World/screenBarModel.mjs`.
No third-party mesh or texture is redistributed.

Reference dimensions: 45 × 9 × 9.2 cm; bar width scaled to 1370 scene units.
The clip, end caps, sensor, control deck, diffuser, optical lip and cable are
separate meshes. Control labels and operational lighting are added at runtime.

## References

- Product and dimensions: https://www.benq.com/en-us/lighting/monitor-light/screenbar.html
- Original user manual: https://www.benq.com/en-us/support/downloads-faq/products/lighting/screenbar/manual.html
- Auto dimming target: https://www.benq.com/en-us/knowledge-center/knowledge/black-friday-lamp-deals.html

A downloadable CC BY Halo model was found at
https://sketchfab.com/3d-models/benq-screenbar-halo-af29991f303748b4a49b06e6e1e07baa
but was not used because it represents a different product with rear lighting
and a separate controller. No usable original AR17 download was found.

## Simulation limits

The original's power, 15 brightness levels, eight 2700–6500 K temperature
presets, tap/hold adjustments, auto indicator, manual exit from auto mode,
and remembered settings are implemented. Auto mode uses a scene-light estimate
with a nominal 500-lux target; this renderer does not measure physical lux.
Three soft forward-facing spotlights approximate its asymmetric linear optics;
this is not a photometrically calibrated manufacturer IES profile. Intermediate
brightness levels and color rendering are visual approximations.
