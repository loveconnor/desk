# Door opening

“dorm door opening.wav” by pagancow: a heavy interior door with a metal
handle opening at a normal pace (1.789 seconds).

Source: https://freesound.org/people/pagancow/sounds/15419/
Asset: https://cdn.freesound.org/previews/15/15419_45698-hq.mp3
License: CC0 1.0, https://creativecommons.org/publicdomain/zero/1.0/

The locally served recording starts with the handle press, at the door's
position. Playback uses the existing master mute, reduced gain, a 110 Hz
high-pass filter for rumble, and a 3.8 kHz low-pass filter to soften harshness.
The lever releases the latch before the door swings, then returns to rest.

`close.wav` is an original synthesized closing effect: a short damped wooden
impact followed by two quiet latch clicks. It plays when the door reaches its
closed position and follows the same positional audio and master mute settings.
