# NuPhy Air75 scene model

Original procedural model; no purchased model, external mesh, or product-photo texture is bundled. The model is authored in millimeters and instantiated at 2.25 scene units/mm, matching the mouse and Nordik desk mat. The exported GLB uses meters.

## Reference and scope

Reconstructed from NuPhy's original Air75 (2021) with COAST **Twilight** keycaps, selected as the closest official dark scheme to the existing scene. The user specified Air75, without a generation or replacement keycap set; this is an explicit modeling assumption, not confirmation of their exact unit.

- [Original product specifications](https://nuphy.com/collections/keyboards/products/air75?variant=39572199014509): 315.7 × 132.6 mm, 84 keys, aluminum frame, ABS lower case, PBT caps, nominal 16 mm profile.
- [NuPhy original design journal](https://pay.nuphy.com/blogs/journal/air75): 16–21 mm profile, recessed aluminum frame, frosted lower case, stainless underside plate, spherical COAST caps, two sidelights and low-profile AirFeet.
- [Official front view](https://i.shgcdn.com/0f25decc-d0d7-4d30-b911-8c1f75ed3aaf/-/format/auto/-/preview/3000x3000/-/quality/lighter/).
- [Official Twilight layout](https://i.shgcdn.com/952de649-40d3-410f-8148-39a259a3f712/-/format/auto/-/preview/3000x3000/-/quality/lighter/).
- [Official keycap detail](https://i.shgcdn.com/b52ac68e-984d-4b6a-811a-fb09a28cee4f/-/format/auto/-/preview/3000x3000/-/quality/lighter/).

Case dimensions and key count come from specifications. Standard 19.05 mm pitch and key-unit widths are matched to the layout image. Corner radii, dish depth, colors, rear port positions, feet and shell segmentation are visual approximations, not manufacturing CAD. Function-row symbols approximate the original pictograms. The lower shell uses an opaque frosted-grey material for lightweight rendering, rather than modeled internal electronics/transmission.

## Implementation

`Air75Layout.ts` defines all 84 keys in six rows, each 16 units wide. Caps share geometry by width and use a shared lit legend atlas. Escape is teal, Enter orange, and Space yellow; the alpha and modifier keys use distinct greys. Each key retains its own group so physical keyboard events can animate its 3.2 mm travel. Fn is modeled but browsers generally do not deliver a standalone Fn event.

The legacy oversized keyboard was replaced without changing its desk center or orientation. The new model rests on the mat. `output/nuphy-air75.glb`, when generated by the preview script, is the same geometry exported in meters; it does not include application key-press logic.

## Model search

Searches for free Air75 models, including Sketchfab and GrabCAD, did not find a usable free complete asset. CGTrader and TurboSquid list a paid BGRT Studio model; it was not purchased, downloaded, or used as mesh/texture input. The reconstruction uses the manufacturer's references above.
